I added a lot of extra attributes to the game; the main one being the Teenage Mutant Ninja Turtle storyline. I love watching TV and playing games, so I knew the game I created either had to be a horror or had to deal with one of my favorite shows. TMNT 2012 was a major part of my life as I watched it probably almost every day, and it helped me bond with my siblings. I learned how to make scripts, how to code a bit, add animations, convert other model files into an FBX through Blender, and create text.
